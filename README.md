# العرض التفاعلي لمقياس الإعلام الآلي — النسخة الثانية

أستاذ المقياس: **السيد نهمار محمد** — السنة الأولى ليسانس، الأدب العربي.
المحتوى: **54 شريحة** = الشرائح الأصلية الـ26 كاملة + **28 شريحة تعليمية جديدة** (عليها شارة ✨).

## 1) التشغيل
1. افتح المجلد `informatique_v2` وانقر مرتين على **`index.html`** — يعمل في Chrome أو Edge دون خادم ودون إنترنت.
2. اضغط **F** لملء الشاشة، و **Esc** للعودة.
3. لا تنقل `index.html` وحده؛ انسخ المجلد كاملاً (يحتاج مجلد `assets` ومجلد `original`).

> دون إنترنت يستعمل العرض خط النظام (Segoe UI / Tahoma) بدل خط Cairo، ولا يتعطل شيء.

## 2) اختصارات لوحة المفاتيح
| الاختصار | الوظيفة |
|---|---|
| `Space` أو `←` أو `PageDown` | الشريحة التالية |
| `→` أو `PageUp` | الشريحة السابقة |
| `Home` / `End` | الأولى / الأخيرة |
| اكتب رقماً (مثال `12`) | انتقال مباشر إلى الشريحة |
| `G` | فهرس الشرائح مجمّعاً بحسب المحاور |
| `F` | ملء الشاشة |
| `T` | وضع التحضير (لوحة الأستاذ) |
| `W` | نافذة الأستاذ المنفصلة |
| `S` | إظهار / إخفاء الحلول على الشاشة |
| `+` `−` `0` | تكبير / تصغير / إعادة حجم النص |
| `P` | العرض التلقائي (لا ينتقل من شرائح الأنشطة) |
| `M` | كتم الصوت |
| `H` | إخفاء / إظهار الشريط العلوي |
| `?` | نافذة المساعدة |
| `Esc` | إغلاق النوافذ |

الاختصارات تتوقف أثناء الكتابة داخل خانات الإدخال.

## 3) وضع التقديم ووضع الأستاذ
- **وضع التقديم (الافتراضي):** شاشة نظيفة للطلبة، بلا ملاحظات ولا نصوص إلقاء ولا حلول.
- **وضع التحضير (`T`):** تظهر لوحة جانبية لكل شريحة فيها: الهدف، نص الإلقاء الأصلي، ما يُقال وما يُنفَّذ، الإجابات الصحيحة، ما يجب أن يظهر على الشاشة، أسئلة متوقعة مع إجاباتها، أخطاء شائعة، والانتقال التالي. وتظهر في الشريحة نفسها صناديق «نص الإلقاء» الأصلية.
- **نافذة الأستاذ المنفصلة (`W`):** للتدريس على شاشتين. شغّل العرض على جهاز العرض واسحب النافذة إلى شاشة حاسوبك؛ تتزامن مع الشرائح وفيها أزرار التالي/السابق. تتطلب السماح بالنوافذ المنبثقة.
- **الحلول (`S`):** تُبرز الإجابات الصحيحة داخل الأنشطة عند الحاجة. وفي كل نشاط زر «إظهار الحل» خاص به.

⚠️ ملاحظات الأستاذ مخفية عن العرض لكنها موجودة في ملف HTML؛ لا تشارك الملف نفسه مع الطلبة إن كنت لا تريد أن يطّلعوا عليها.

## 4) أنواع الشرائح
- **شرائح الشرح:** الشرائح الأصلية كما هي.
- **✨ نشاط تفاعلي:** تصنيف، مطابقة، ترتيب خطوات، «اكتشف الخطأ»، تعبئة حقول، قائمة تحقق. تعطي تغذية راجعة فورية ولا تكشف الإجابة قبل المحاولة (إلا بزر «إظهار الحل»).
- **✨ محاكاة:** نوافذ توضيحية خطوة بخطوة (الوضع الآمن، استعادة أيقونة «هذا الكمبيوتر»، مستكشف الملفات، بناء شجرة المجلدات). انقر العنصر المضيء أو زر «الخطوة التالية»، وزر «إعادة التجربة» يعيدها. **هي محاكاة تعليمية وليست برنامج ويندوز الحقيقي**، وبجانبها خطوات التنفيذ على الحاسوب الحقيقي.
- **✨ اختبار قصير:** في نهاية كل جزء، ونتيجته تقترح الشرائح التي يراجعها الطالب.

## 5) مجلدات المشروع
```
informatique_v2/
├── index.html            ← العرض المطوَّر
├── assets/css/           ← tailwind.css (مُصرَّف محلياً) و v2.css
├── assets/js/app.js      ← التنقل والأنشطة والمحاكيات ووضع الأستاذ
├── original/             ← الملف الأصلي دون تعديل + ملف PowerPoint الأصلي
├── التقرير.md            ← الشرائح الجديدة والتحسينات والتنبيهات
└── نتيجة_التحقق.md       ← نتيجة التحقق من حفظ المحتوى الأصلي والاختبارات
```

## 6) تعديل العرض
- تغيير نص موجود: عدّله في `index.html` مباشرة.
- إضافة عناصر بأصناف Tailwind جديدة قد تحتاج إعادة تصريف `tailwind.css` (الأصناف المستعملة حالياً فقط موجودة فيه).
- ملف PowerPoint الموجود في `original/` يخص النسخة الأصلية (26 شريحة) ويُنزَّل من الشريحة الأخيرة.

## 7) تنبيهات
- جُرِّب العرض آلياً على Chromium (محرك Chrome وEdge). يُستحسن تجربته مرة على حاسوب القاعة قبل الحصة.
- أسماء قوائم ويندوز وخطوات الوضع الآمن وخيار الإسبات تختلف قليلاً بين الإصدارات؛ راجع ملاحظات الأستاذ في الشرائح المعنية.
